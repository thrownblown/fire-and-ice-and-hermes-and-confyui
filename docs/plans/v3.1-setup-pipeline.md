# Fire & Ice — v3.1 Setup-Driven Pipeline Spec

*Locked 2026-10-12 (Alex). Supersedes the 2026-09-27 chunk-pack framing in
`docs/test-runs-plan.md` and the open X1–X4 question in `docs/plans/setup-ref2va-tests.md`:
the deliverable is now a per-shot three-track candidate pool + triage, not a semi-manual chunk pack.*

## Architecture philosophy

The pipeline inverts the standard AI-video workflow. The script is the absolute source of
truth, dictating all chronology and pacing. To prevent visual hallucination across cuts,
shots are processed by Setup (camera angle) rather than in chronological chunks.

## 1. Core engineering directives

- **Hardware split.** The 4090 = orchestrator, Web UI, LM Studio VLM host. The 5090 =
  exclusive heavy H3 render node (~23 GB per model). Never run H3 + LM Studio on one GPU.
- **X4 splicing rule.** No long setup reference concats. Single-shot video + single-shot
  audio + a shared master background plate (the X4 approach). X1/X2 (setup-concat) abandoned.
- **Ledger-driven motion.** The VLM (`qwen3-vl-8b`) does appearance/identity labeling only.
  Physical actions and camera moves are seeded from the chunk ledger's `motion[]` /
  `shot_type[]` / `angle[]` fields — never invented by the VLM.
- **Setup-driven batching.** Renders are batched to the 5090 by `setup_id`, not narrative order.

## 2. The 3-track generation matrix

Every shot renders across three parallel tracks; all use the original Bakshi `.wav` stem to
drive timing and jaw movement.

| Track | Name | Grammar | Payload | Focus |
|---|---|---|---|---|
| A | Rotoscope | 6-field REF2VA | Bakshi video ref + master setup plate + character stills + audio | choreography, 1:1 motion tracing |
| B | Cinematic Restage | 3-field FL2VA / t2v (`integrated_multimodal_description`) | master setup plate + character stills + audio (NO video ref) | 3D physics/camera from text only; escapes flat 1980s framing |
| C | Boundary Lock | 3-field FL2VA | FFLF (first/last frame) + character stills + audio | stylized locked-off dialogue; interpolate between two ComfyUI paintings |

Grammar constraints: FL2VA and REF2VA are strictly mutually-exclusive endpoints — routing all
three through one generic payload causes fatal API rejections. A = 6-field; B/C = 3-field.
Track B MUST omit all `<Video N>` retention lines (dead-reference failures).

## 3. Step-by-step pipeline

**Stages 1, 3, 4, 4B — COMPLETED.** 1308 shots extracted; ~704 setups logged to
`manifests/continuity_v2.jsonl`; 494 chunks assembled; single-shot `.mp4`/`.wav` refs and
FFLF stills sliced.

**Stage 2 — Master asset generation.** Lock visual identity. Characters: verify Frazetta
character sheets (via existing Civitai LoRA pipelines). Plates: generate ONE master Frazetta
matte painting per Setup → `refs/setups/{tag}_plate.jpg`.

**Stage 5 — Prompt compilation (`sulphur_2_prompt_enhancer`).** Track-specific API syntax.
- Inheritance: query `manifests/continuity_v2.jsonl`; every shot in a setup inherits that
  setup's environment description + `{tag}_plate.jpg` background.
- Motion splicing (Tracks B/C): merge VLM appearance data with structural motion data from the
  chunk ledger.
- Controlled vocabulary: strict H3 natural-English camera prose ("The camera pans right with
  large amplitude at fast speed"), exactly ONE valid move (pan/truck/tilt/push-in/pull-out/
  arc/tracking/static/shake/POV/roll) + ONE physical action per shot. No bracketed camera
  commands.
- Grammar: 6-field REF2VA for A; 3-field FL2VA for B and C.

**Stage 6 — Batch generation (5090 queue).** Orchestrator batches by `setup_id` (all S06-A
before S06-B) for cross-cut consistency. 5090 executes Tracks A/B/C per shot. Outputs →
`sNN/renders/shotID_trackA.mp4` etc.

**Stage 7 — Triage & reassembly.** Curation UI shows the 3 candidates (A/B/C) beside the
Bakshi reference; pick the winner. Assembly queries selected renders by chronological
`shot_id`, FFmpeg concat, continuous original audio mix laid over.

## Implementation-time notes (not blocking)

- Track B and Track C share the 3-field grammar but are different graph modes: B = t2v /
  plate-reference (no temporal anchors), C = FL2VA first/last-frame conditioning. Do not reuse
  the FL2VA graph for B without confirming a t2v node exists on the 5090.
- "Master plate" = a generated Frazetta matte painting, distinct from the collage contact-sheet
  plate `tools/build_setup_refs.py` currently emits under the same `{tag}_plate.jpg` name.
