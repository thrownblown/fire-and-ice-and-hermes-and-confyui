Four links shared by Alex. Two are mature, open-source H3 film-production apps — the closest

## 0. Official MiniMax H3 prompt-writing guides (now in-repo)
Downloaded to `docs/h3-official/` from `huggingface.co/MiniMaxAI/MiniMax-H3/docs`:
- `VIDEO_PROMPT_WRITING_GUIDE_base_en.md` (15.8 KB) — T2VA / I2VA / FL2VA / L2VA. Sections:
  task overview, the 3-field final structure (instruction part + `integrated_multimodal_description`
  / `overall_soundscape` / `non_diegetic_music`), how to incorporate keyframes, how to write each
  section, shots/cuts, **camera motion = motion type + amplitude + speed**, speakers/dialogue/singing,
  on-screen text.
  sha256 `2cfebc09…`.
- `VIDEO_PROMPT_WRITING_GUIDE_ref_en.md` (23.6 KB) — the REF2VA (full-reference) six-field guide.
  sha256 `1e574f35…` — **byte-identical to the hash Lumibelle pins**, so it is the exact official file.
- These are the authoritative source for our two grammars; the skill's community-derived notes are
  now backed by the vendor spec. The base guide's "motion type + amplitude + speed" is exactly our
  camera vocabulary rule, and §4.4 is the dialogue/speaker format.

The ref guide's key contract (from the Frameforge copy, identical file): four label types —
`<Subject N>` = reusable visible content; `<Picture N>` = a concrete frame / shot-planning anchor;
`<Video N>` = whole-video relationship (edit source, continuation start, or temporal structure);
`<Audio N>` = copied/referenced audio. A `<Picture N>` gets its OWN line only when it is a first/
last frame, keyframe, edited keyframe, composition anchor, or storyboard reference; if the image
merely defines a character/scene/costume/style it is cited INSIDE the `<Subject N>` definition
instead. A person/object/scene/action reused from a video still belongs under `<Subject N>` —
`<Video N>` names the asset, it does not replace subject labels.

## 1. Lumibelle + SparkleRiley (radiatingreverberations) — the closest peer to FNI
- Reddit: part 1 r/StableDiffusion 1wtfwmp (2026-09-29, 48 up); part 2 1wycwqr (2026-10-05, 65 up)
- Tool: https://github.com/radiatingreverberations/lumibelle (C#/Razor/JS desktop app, 1385 files,
  758 `.cs`, 456 tests, CI) — "a personal video studio for growing an idea into a film."
- Project: https://github.com/radiatingreverberations/sparkleriley — a COMPLETE episode as data:
  screenplay, characters, environments, props (each with reference images + reels + **voices**),
  shots with prompts and takes, and the final cut. CC0. 791 files (222 png, 208 mp4, 64 json).
  Each asset is a folder of `images/` + `voices/`; `assets.json` + `ai-preferences.json` at the root.
  This data model maps almost 1:1 onto FNI's characters / setups / shots / takes.

### 1a. Measured acceleration benchmark (the most valuable thing in this batch)
`docs/h3/acceleration-benchmark-2026-09-11.md` — real timings, one isolated worker, **RTX 4000 Ada
20 GB**, ComfyUI 0.35.0, base pruned **W4A8** Ref2VA + W4A8 encoder, int8 video VAE, fp32 audio VAE,
141 frames @ 24 fps, 832×480 → FP16 Upscaler-Plus to 1344×768, seed 20260911, one seed, dialogue +
motion prompts. Total pipeline seconds (prep+sampling+upscale+decode+archive+save):

| Recipe | Dialogue | Motion | User: dialogue | User: motion |
| --- | ---: | ---: | --- | --- |
| Standard 20-step | 400.95 | 426.32 | OK | Good |
| Turbo 4-step | 254.72 | 264.31 | OK | **Poor; weird interiors** |
| Turbo 8-step | 294.41 | 307.70 | OK | **Poor; weird interiors** |
| Standard + Spectrum | 335.81 | 354.20 | OK | **Poor; weird interiors** |
| PDD Ref2VA 8-eval | 289.68 | 295.98 | **Strongly distorted** | Good |
| **Larry v4 step600 EMA, 6 steps** | 276.37 | 282.09 | OK | **Good** |

- **Larry v4 step600 EMA at 6 steps was the winner** — 31–34 % faster than Standard and the only
  accelerated recipe judged acceptable on both scenes. Recipe: dedicated pruned-model LoRA loader,
  v4 step600 EMA, strength 1, `low_vram=false`, custom Turbo sampler, simple schedule, 6 steps.
  **The LoRA alone is not enough** — it needs Larry's node pack
  (`github.com/Larryvrh/ComfyUI-MiniMax-H3-Turbo`, nodes *MiniMax-H3 Turbo LoRA* + *MiniMax-H3 Turbo
  Sampler*), added to `tools/install_5090_nodes.sh`. His README: v4-600 EMA is the recommended
  checkpoint; use **6–8 steps** (at 4 steps with large/fast motion v4 can smear → the older v1 ~850
  is friendlier there); v4 fixed the plastic/over-sharp look of v1; audio and fast motion are still
  being improved.
- PDD: good motion, but dialogue "strongly distorted" — motion-only, not for speech.
- Spectrum and the 4/8-step Turbos all gave "weird interiors" on the motion scene.
- Failures: **Sol-Attn** died before sampling with `BlockSparseAttention.execute() missing
  'selection'` (node-input integration bug, not the method); **FirstBlockCache Safe** exited 134 with
  `CUDA error: invalid argument` in `CUDAMallocAsyncAllocator::free_impl`.
- Caveats stated by the author: single seed, one GPU, no second-seed/warm-process/Native/243-frame
  follow-ups; quality labels are the user's direct review, no perceptual metric.
- **FNI relevance:** our refrun.py runs the 4-step turbo at strength 1.0 — this data puts that in the
  "Poor; weird interiors" row. Larry 6-step is the evidence-backed replacement (see the download list).

### 1b. Motion extension — an exact, stock-node contract
`docs/h3/motion-extension.md`. Numbers worth keeping:
- Frame grid `17k+5`, rounded UP, **max 362 frames @ 24 fps**. Video latent steps =
  `2 + 5 * ((frames - 5) / 17)`; **audio boundaries at 40 latent steps/second**; context prefix
  removed ONCE from delivered video and audio; **assembly adds no fades or frame blending**.
- Context windows: **39, 22, or 5 visible decoded frames** (shorter clips use one frame) through
  stock `MiniMaxH3AddGuide`; "saved motion" copies a compatible **39-frame window** into new padded
  `.latent` tensors with **fresh noise before it**.
- Uses **STOCK ComfyUI nodes only** — `LoadLatent`, `SetLatentNoiseMask`, `LTXVConcatAVLatent`,
  `MiniMaxH3AddGuide`. No custom node pack. (This is a genuine alternative to our
  `MiniMaxH3MotionContext` chain — same job, vendor nodes, no third-party pack.)
- **Lead-in** generates FORWARD in time toward a held ending window — footage and audio are never
  reversed; the ending overlap is removed once, then the original footage/soundtrack follow.
- Continuation snapping: "Snap end for continuation" on when compatible latents + 39 visible context
  frames exist; the start handle is never snapped.
- Compositions store flat ordered segments, each mapping a visible range into an independently
  retained full generation; combined takes may exceed 362 frames, individual generations may not.
- **FNI relevance:** directly comparable to our T0010 chain and the wjc_5 recipe. A/B candidate.

### 1c. Character capture reels — a concrete turntable recipe
`docs/h3/character-capture-reels.md`. 10 requested seconds → **243 frames = 10.125 s** (grid rounds
up). Default "All angles → face" plan:
| Interval | Capture |
| --- | --- |
| 0–0.250 s | brief frontal full-body hold |
| 0.250–6.125 s | camera travels a full horizontal circle: front → anatomical right profile → back → left profile → front, through the 3/4 views |
| 6.125–8.125 s | camera stops at front; raise and lower both arms |
| 8.125–10.125 s | one cut to a stationary frontal face close-up |
Person stays stationary, head/gaze toward the original front (does NOT follow the camera). Movement
∈ None / Arms / Knee; Push-in replaces the final cut with 1 s approach + 1 s settle (continuous).
At 5–<8 s it switches to five roughly equal held views with clean cuts (front, right, back, left,
face). Six further variants exist (identity-first neutral turntable, silhouette reveal, pose-expansion,
bend/waist/drape, sitting-to-standing, face-priority).
**FNI relevance:** this is a ready-made, precise version of our "turntable identity reel" — adopt the
interval plan for our character reels instead of ad-hoc turns.

### 1d. Voices
- `character-voices.md`: one optional **default voice recording per character, shared across looks**;
  excerpt length **1–15 s**; voice choice is independent of the visual references; soundtrack is
  extracted locally to an independent WAV (no speech isolation).
- `character-speech.md`: speech is independent of the framing preset; scene/camera prose stays
  English while `Language` + `Line` hold the exact spoken language and words — **never translated or
  refilled when settings change**. Validation is the exact `<d>[Language] words</d>` form.
- Language capability (from the MiniMax repo, checked 2026-09-18): stable generated dialogue for
  **Arabic, Chinese, English, French, German, Italian, Japanese, Korean, Portuguese, Russian,
  Spanish**; others "supported to varying degrees". Voice framing preset = stationary near-frontal
  head-and-shoulders, unobstructed mouth.
- **FNI relevance:** our 223 curated voice lines → 1–15 s excerpts, one default per character.

### 1e. HyperFlow 8-step — a frozen ComfyUI recipe
`docs/h3/hyperflow.md`. 8 Euler intervals, `LoraLoaderModelOnly` strength 1.0, `MiniMaxH3SigmaShift`
video 12 / audio 3, `BasicGuider` (no negative/CFG), `euler`, `ManualSigmas` with the **video-shifted**
grid, full 1→0 denoise (no partial-denoise truncation):
```
1.0, 0.9939097854, 0.9842874953, 0.9660637197, 0.9230769231,
0.8349423898, 0.6968520491, 0.4687533149, 0.0
```
Shift transform: `shifted = shift * raw / (1 + (shift - 1) * raw)` — ComfyUI's native `ManualSigmas`
does NOT apply it, so the graph supplies the already-shifted numbers AND sets shifts 12/3. The
drbaph conversion model card is internally inconsistent (lists both raw and shifted sequences).
Files: `minimax_h3_hyperflow_8step_v1.0_comfyui_pruned_bf16.safetensors` (+ resized/full variants).

### 1f. Preset menu (Lumibelle, as of 2026-10-06)

## 2. Frameforge / "Chain-Motion-AI-Video-Editor" (Super_Range45) — FilmCraft
- Reddit: r/StableDiffusion 1x4fq9m "FilmCraft, This entire movie was rendered as one sequence.
  Update 1" (2026-10-12, brand new). Author: 7 minutes in 3 weeks, ~**1,700 video generations**
  (mostly low-res drafts), H3 through his own ComfyUI toolset.
- Repo: https://github.com/spacesimeco-hue/Chain-Motion-AI-Video-Editor (130 files; Python service
  + browser editor, no build step).
- Features: single-track generative timeline; reference library (images/video/audio, frame capture,
  audio trim); H3 text+multimodal generation with **local latent motion continuation**; Scene Writer
  (structured scripts → segments); **Speech Studio** (dialogue from a short voice ref via the
  **LTX 2.3** workflow); **Set Studio** — Gaussian-splat reconstruction, stage mannequins + GLB
  props, pose limbs/fingers, save cameras, **render reference images**; Qwen image editor (up to 9
  extra image refs); optional Comfy Cloud + a 4-step Turbo LoRA; job tracking with downloadable API
  graphs; export a sequenced MP4 or a ZIP of clips + a scene/prompt manifest.
- Continuation workflows are pinned by context length: `Work Flows/Cloud/continuation-22.api.json`,
  `-39-`, `-56-` — i.e. **context lengths 22 / 39 / 56**, matching the enum our `core/h3_chain.py`
  already uses (`context_length` 5/22/39/56). Independent corroboration of the same grid.
- Comment thread: boundary flashing / frame-texture changes at 0:19 and 0:24; the author says
  "that's the model's issue — if there's a workflow that can smooth that out, I'd love to implement
  it"; Apprehensive_Sky892 suspects the upscaling introduces it and links a YouTube timestamp.
- **FNI relevance:** (i) Set Studio is a *master-plate generator* — stage a 3D scene and render
  reference images for a setup, which is exactly our "generated Frazetta plate" need; (ii) Speech
  Studio uses LTX 2.3 for voice, an alternative to H3-native voice cloning; (iii) the same
  continuation context lengths we use, from an independent implementation.

## 4. What this changes for FNI (short list)
1. **Turbo LoRA:** our 4-step @ 1.0 is the measured-weak option; adopt/test **Larry v4 step600 EMA @ 6
   steps** (added to `tools/download_5090_models.sh`).
2. **Motion continuation:** Lumibelle's stock-node contract (39/22/5-frame contexts,
   `MiniMaxH3AddGuide` + `SetLatentNoiseMask` + `LTXVConcatAVLatent`, no custom pack) is a second
   mechanism to A/B against our `MiniMaxH3MotionContext` chain and the wjc_5 dual-sampling recipe.
3. **Character reels:** adopt the 243-frame orbit/articulation/close-up interval plan for identity refs.
4. **Voices:** 1–15 s excerpts, one default voice per character, exact `<d>[Language] words</d>`.
5. **Prompt grammar:** we now hold the official 3-field and 6-field guides in `docs/h3-official/`.
   Reconcile `refrun.py`'s builder with the official `<Picture N>`-vs-`<Subject N>` rule.
6. **Master plates:** Frameforge's Set Studio (3D staging → rendered reference images) is a concrete
   route to the generated per-setup plate we specified.
